PROJECTS

Agentic Self-Managing Memory and Project System

Building an AI agent harness with permanent, total context: it knows the user's projects, history, and past decisions, so nothing ever has to be re-explained. The more work runs through it, the sharper it gets. Lessons carry forward automatically, and the memory underneath manages itself. The whole system is hosted on a Linux VPS, always on and reachable from anywhere. Each capture, from passing ideas to major decisions, feeds a custom pgVector RAG pipeline that surfaces the right memories at the right moment.

Automated Job Search Board with AI Matching

Built a system that automates the job hunt end to end. It watches 500+ company career boards around the clock and uses Claude to judge every posting against a candidate profile, surfacing only the strong matches. Once an application is in, tracking runs itself: an AI email classifier reads employer replies and advances each application's status, escalating to a human only when it's unsure. Fully self-hosted and running unattended on a Linux VPS.
